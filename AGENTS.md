## Development & Code Standards

1. **GDScript Standards**:
   - Use static typing wherever possible (`var count: int = 0`, `func _ready() -> void:`).
   - Follow standard GDScript formatting and naming conventions (`PascalCase` for classes/nodes, `snake_case` for variables/functions, `UPPER_SNAKE_CASE` for constants).
   - Retain `.uid` files generated by Godot 4 for resource identification.
   - Maintain modular OOP structure with single responsibility principle across components.

2. **Addon Management**:
   - Treat `addons/dialogic/` as a managed plugin. Avoid editing core Dialogic plugin files directly unless creating custom extensions or modules within `addons/dialogic/Modules/`.

3. **Git & Sync Rules**:
   - All commits should follow conventional commit message formats (e.g., `feat:`, `fix:`, `docs:`, `refactor:`).
   - Ensure the working tree is clean and synced with remote `origin/main` after completing major tasks.
